# Roadmap: October 2026–October 2027

These are intended priorities, not completed work or promised delivery dates.
Security and correctness fixes take precedence over new features.

1. Preserve deployed configuration contracts and expand synthetic runtime regression coverage for maintenance, notifications and device recovery.
2. Audit owned camera, notification and maintenance transports and versioned runtime dependencies; document and test secure deployment profiles without silently changing the running home.
3. Improve reproducible source assembly and update/rollback evidence across supported Home Assistant versions.

A backup maintainer and tested one-week recovery procedure are still absent.
The maintainer will document an actual continuity arrangement when one exists;
a plan or automation account does not satisfy that requirement. Changes to
physical installations require operator review and device-specific acceptance.
